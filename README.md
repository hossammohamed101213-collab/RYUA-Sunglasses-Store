# RYUA (رويا)

نسخة مستقلة من موقع SAHRRA المرجعي، مع الحفاظ على هيكل الصفحة، الأقسام، النوافذ، الثيمات، تجربة الهاتف والكمبيوتر، السلة، والتخصيص. تم استبدال الهوية والمحتوى والصور لتناسب متجر نظارات شبابي فاخر باسم RYUA.

## التشغيل والمعاينة

افتح `dist/index.html` في المتصفح بعد فك الضغط. يمكن أيضًا تشغيل مجلد `dist` عبر أي خادم ملفات محلي لمعاينة أكثر استقرارًا.

## ما تم تغييره

- العلامة: RYUA / رويا.
- المنتجات: نظارات بدل العبايات، مع صور منتجات جديدة.
- النصوص والبيانات الوصفية ووصف المنتجات.
- العبارات الخاصة بصاحب المتجر بصيغة المذكر.
- ألوان وصور الحملة المرتبطة بالمنتج الجديد، مع الحفاظ على تجربة القالب الأصلية.
- مفاتيح التخزين المحلية أصبحت خاصة بـ RYUA.

## ما يعمل

- الثيمات، اللغة، الحركة الهادئة، الأقسام، التصفية، المقارنة، تفاصيل المنتج، التخصيص، والسلة.
- حفظ بعض الاختيارات محليًا على الجهاز.
- تجهيز رسالة طلب عبر واتساب.

## ما يحتاج ربطًا حقيقيًا

- لم يتم توفير رقم واتساب لـ RYUA؛ روابط واتساب تحتاج تحديثًا قبل النشر.
- لا يوجد دفع إلكتروني أو لوحة إدارة أو قاعدة بيانات أو حفظ طلبات على خادم.
- التقييمات والإدارة واجهات فقط ومعلّقة حتى ربط خدمة حقيقية.

تم استبعاد بيانات Git وملف الإدارة التجريبي وأي إعدادات ربط تخص المشروع الأصلي.
